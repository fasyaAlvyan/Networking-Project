# Designing a Resilient Enterprise LAN: Three-Tier Architecture with OSPF, VRRP, RSTP & LACP
Proyek ini merupakan simulasi jaringan untuk ketersediaan tinggi dengan mengkombinasikan/mengintegrasikan protokol seperti *Open Shortest Path First(**OSPF**), Virtual Redundancy Router Protocol(**VRRP**), Rapid Spanning Tree Protocol(**RSTP**) dan Link Agregation Control Protocol(**LACP**)*
,keempat protokol ini berguna untuk menyelesaikan masalah tiap kelemahan pada desain jaringan untuk mencapai tingkat ketersediaan tinggi dan tahan terhadap kegagalan dengan metode menyediakan banyak backup untuk setiap device *intermediary* dan media transmisi(*Ethernet cable*), jika ada kegagalan perangkat yang disediakan sebagai backup akan menghandle sementara agar koneksi client tidak terputus. Keempat protokol ini memiliki perannya masing masing di dalam jaringan.
## Fungsi dari setiap protokol pada jaringan High Availability(HA) ini :
- OSPF : OSPF berperan sebagai protokol dinamis yang melakukan perhitungan untuk menentukan rute terbaik atau melakukan rekalkulasi saat sebuah link putus memindahkannya ke link lainnya dengan waktu konvergensi selama 40 detik(untuk jaringan BMA) atau kurang.
- VRRP : VRRP berperan sebagai protokol yang membagi 1 IP virtual dan 1 MAC virtual (0000:5E0002:00xx) untuk dipakai oleh 2 atau lebih perangkat L3, dengan menetapkan peran MASTER dan BACKUP pada perangkat untuk menentukan siapa yang menjadi backup dan primer,setelah peran ditetaokan, Primer akan menjadi gateway dan terus mengirim VRRP hello kepada setiap backup dengan interval default 1 detik untuk memberitahu backup jika master masih aktif/tidak.
- RSTP : RSTP berperan sebagai protokol untuk mencegah looping karena dalam jaringan ini ada banyak sekali link yang redundant dan berpotensi menyebabkan broadcast storm jika tidak memakai RSTP, saat ada kegagalan switch akan mengkalkulasikan ulang dan mengaktifkan lagi link alternate/backup untuk menjadi designated port/root port agar konektivitas tetap berjalan.
- LACP : LACP berperan sebagai protokol untuk meningkatkan bandwidth dan toleransi pada kesalahan dengan metode menggabungkan 2 atau lebih link menjadi 1 link logis,LACP mengatur Link Agregation Group agar link di dalam group/bonding tetap valid menggunakan mekanisme pengiriman LACPDU disetiap linknya dengan interval yang bervariasi,LACP akan mengeluarkan link yang mengalami kegagalan agar LAG tidak memasukkannya kedalam algoritma XoR yang berpotensi menyebabkan Black hole.
